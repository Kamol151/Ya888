# Velvet Royale Baccarat — Online Multiplayer

เกมบาคาร่า Punto Banco สำหรับความบันเทิงด้วยเหรียญจำลองเท่านั้น ไม่มีเงินจริงหรือระบบฝากถอน ไพ่ถูกสับ แจก และตัดสินโดย Node.js server แล้วซิงก์ผ่าน Socket.IO ให้สมาชิกห้องเดียวกันเห็นรอบเดียวกัน

## รันบน Windows

1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/ แล้วปิด/เปิด Terminal ใหม่
2. แตก ZIP และเปิดโฟลเดอร์โปรเจกต์ `realistic-3d-baccarat`
3. คลิกแถบที่อยู่ใน File Explorer พิมพ์ `cmd` แล้วกด Enter
4. ติดตั้ง dependencies (ทำครั้งแรกครั้งเดียว):

   ```bash
   npm install
   ```

5. เปิด Frontend และ Backend พร้อมกัน:

   ```bash
   npm run dev:online
   ```

6. เข้า http://localhost:5173 และปล่อยหน้าต่าง Terminal เปิดค้างไว้

> อย่าใช้ `npm run dev` อย่างเดียว เพราะคำสั่งนั้นเปิดเฉพาะหน้าเว็บ ไม่ได้เปิดเซิร์ฟเวอร์ Socket.IO

## ห้องและการทดสอบ Multiplayer

- ทุกคนที่เข้าเว็บครั้งแรกจะเข้าห้อง `PUBLIC-01` อัตโนมัติ
- กด **สร้างห้อง** เพื่อสร้างรหัสห้องส่วนตัวแบบสุ่ม แล้วส่งรหัสให้เพื่อน
- ปุ่ม **เริ่มรอบ** ใช้ข้ามเวลานับถอยหลังของรอบปัจจุบันได้หนึ่งครั้งต่อรอบ; หากไม่กด เกมจะเริ่มเองหลังนับถอยหลัง 10 วินาที
- เพื่อนใส่รหัสเดียวกันในช่องรหัสห้องแล้วกด **เข้าห้อง**
- กด **กลับ PUBLIC** เพื่อออกจากห้องปัจจุบันแล้วกลับไปห้องสาธารณะ
- รหัสห้องที่ใช้อยู่จะถูกจำในเบราว์เซอร์ เมื่อรีเฟรชจะพยายามกลับเข้าห้องเดิม ตราบใดที่เซิร์ฟเวอร์เดิมยังทำงาน
- ทดสอบสองหน้าต่างได้โดยเปิด URL เดิมคนละแท็บ ทั้งสองควรเห็นไพ่/ผล/ตัวจับเวลาของห้องเดียวกัน
- ในเครือข่าย Wi-Fi เดียวกัน เปิด `http://IP-ของเครื่องที่รันเซิร์ฟเวอร์:5173` เช่น `http://192.168.1.70:5173` และอนุญาต Node.js ผ่าน Windows Firewall หากมีหน้าต่างถาม
- ในโหมดพัฒนา Frontend ต่อ Socket.IO ที่พอร์ต `3001` โดยตรง จึงต้องอนุญาตพอร์ตนี้ใน Firewall ด้วยเมื่อใช้เครื่องอื่นใน LAN

## นำขึ้นอินเทอร์เน็ตจริงด้วย Render

1. อัปโหลดโฟลเดอร์โปรเจกต์ไปยัง GitHub repository ของคุณ
2. เข้า https://render.com แล้วสร้าง **New Web Service** เชื่อม repository
3. ตั้งค่า Build Command: `npm install && npm run build`
4. ตั้งค่า Start Command: `npm start`
5. Runtime เป็น Node; ใช้ไฟล์ `render.yaml` เป็นตัวอย่างค่าตั้งต้นได้
6. เมื่อ Deploy สำเร็จ ให้เปิด URL HTTPS ที่ Render ให้มาแล้วแชร์ URL และรหัสห้องให้เพื่อน

เซิร์ฟเวอร์ production ใช้ `PORT` ที่ผู้ให้บริการกำหนดและให้เว็บกับ Socket.IO ใช้ origin เดียวกัน ไม่ต้องเปิดพอร์ต 3001 สู่สาธารณะใน production

## คำสั่ง npm

- `npm run dev:online` — รัน Vite + Socket.IO backend สำหรับพัฒนา
- `npm run build` — สร้างไฟล์เว็บใน `dist`
- `npm start` — เสิร์ฟเว็บ production และ Socket.IO (ต้อง `npm run build` ก่อน)
- `npm test` — ทดสอบกติกาเกมเดิม

## ข้อจำกัดที่ควรรู้

- สถานะห้องและประวัติอยู่ในหน่วยความจำของเซิร์ฟเวอร์ จะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต และยังไม่มีฐานข้อมูลถาวร
- เกมมีตัวละครเจ้ามือแบบ 2.5D ที่สร้างด้วย CSS ไม่ใช่โมเดล 3D เต็มรูปแบบ
- เสียงประกาศใช้ Text-to-Speech ของเบราว์เซอร์ อาจต้องกดเปิดเสียงก่อน และเสียงภาษาอังกฤษขึ้นกับอุปกรณ์
- เหรียญ/แผงเดิมพันเดิมยังเป็นโหมดฝึกส่วนตัว ไม่ซิงก์เดิมพันระหว่างผู้เล่น
- เกมจำลองเพื่อความบันเทิงเท่านั้น ไม่มีเงินจริง
